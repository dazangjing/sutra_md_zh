# 律宗

律宗以「以戒为师、依戒持戒」为唯一宗主，以戒藏为根本，专以四分律为主，兼取僧祇、十诵、弥沙塞诸律互校，故律宗又称「毗尼宗」「戒宗」。其修行的实际形态可分五层：一曰受持戒本（比丘、比丘尼、沙弥、沙弥尼、优婆塞、优婆夷、菩萨戒），二曰依律运作（结界、说戒、布萨、结夏、说戒自恣、授受衣药）；三曰律藏疏释（行事钞、戒疏、羯磨疏、毗尼作持论）；四曰僧团清规（百丈清规以下历代丛林规制）；五曰忏悔灭罪与临终助亡。本辑据此「根本戒经 → 律藏解读 → 戒本受戒 → 僧团清规 → 忏悔灭罪」次第编排，末附论疏要籍、律宗传承史传与近代讲录，使学者由「持何戒、如何持、如何摄受众僧、如何忏悔除罪」四条线索入手。
