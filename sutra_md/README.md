## 五、单档之结构

```
# 题名                                  ← 繁体题名转简体

> **藏经**：大正新修大藏经（大正藏）　**册次** 第 13 册（T13）　**编号** No. 397（T0397）
> **部类** 大集部　**卷次** 60 卷　**篇幅** 694,165 字
> **作者（译者）**：北凉天竺三藏昙无谶於姑臧译
> **卷／品**：61 卷 · 99 品

---

## 目录                              ← 卷、品两级锚点目录（无卷无品者则整节省略）

- [大方等大集经卷第一](#大方等大集经卷第一)
  - [璎珞品第一](#璎珞品第一)

---

## 大方等大集经卷第一                ← 卷：每卷一块

**译者**：北凉天竺三藏昙无谶於姑臧译

### 璎珞品第一                      ← 品：每品一块

> 「如来光明胜一切，  能坏三恶道黑暗，   ← 偈颂：引用块（`>`），块内保留硬换行
> 今我归依乐依止，  萨婆悉达无上尊。」

……正文……
```

- **卷／品独立分割**：卷题行升 `##`，品题行升 `###`；块间以 `------` 分隔。
- **偈颂结构化标记**：偈颂行（含两个全角空格者）整段以 `> ` 引用块包裹；偈颂行内
  **两个以上连续全角空格**（CBETA 半句排版分隔符，其前必为标点）去之，
  **单个全角空格**（陀羅尼咒语之音节分隔）保留。
  判据另排除 **ASCII 制表图**（王系世谱等以 `┐ ┌ └` 排版者，虽含全角双空格却非偈颂），
  以免图表被误作引用块——全库此类误判 **0**。
- **正文逐字保留**：仅删 CBETA 结构标记行——档号行 `No. N` 与卷末题（与卷题重复之收卷行）；
  正文文字一字未改。段内多行以行尾两空格还原硬换行。

## 六、分类规则

依仓库自有规则表 `tools/rules_block.py`（分层：特殊类目 → 疏类 → 主旨 → 诸宗 → 兜底）
判别部别，**逐档归属依据写入 `index.json` 之 `basis` 栏**，可复核。常用依据示例：

| 依据 | 归属 |
|---|---|
| 题尾「经」归经集部 ／ 单译小经归经集部 | `9_经集部` |
| 经疏注记类题名 | `17_经疏部` |
| 宗派语录颂类题名 | `20_诸宗部` |
| 题尾录传类归史传部 ／ 方志类题名归史传部 | `21_史传部` |
| 密教仪轨陀罗尼特征 | `10_密教部` |
| 目录题名 | `24_目录部` |
| 近现代著作，不入二十六部；作者属近现代 | `27_近代撰述` |

### 合并档

字母变体档（如 `T0128a`／`T0128b`）若为**同一部佛经之上下卷**（判据：上卷末行即卷末题、
下卷首行即同一卷题，且下卷无独立 `No.` 档号行），则按上下顺序**合并为单一档案**
（`T0128.md`），源分卷一并并入。本库共合并 **33 组、85 档**；其 `catalog_work_ids`
保留各成员之 CBETA 著录号，可回溯至原分卷。

## 七、繁简转换规则

字表 `t2s_map.json`（取自 OpenCC `TSCharacters.txt`）：

| 情形 | 处理 |
|---|---|
| 繁体有唯一对应简体（4,057 字） | 转简体 |
| 一繁对多简而仅一个常用简体（32 字，如 開→开、線→线、麵→面） | 转该常用简体 |
| **一繁对多简且语义真歧义（24 字）** | **保留繁体原字** |
| 无对应简体之生僻字 | 保留原字 |
| **组合表示式**（`[薩-產+(辛/工)]`、`[□@考]`） | **不翻译**，原样保留 |

歧义字保留举例：`乾／於／畫／餘／覆／麼／祇／藉／諮` 等。兼容汉字区（U+2F800–2FA1D）
之繁体字形亦一并转换（全库 3,728 处）。

## 八、异常字符

全库扫描后，**真正需人工订正者 34 处、8 种字符**：

| 字符 | 码位 | 类别 | 出现 |
|---|---|---|---:|
| `⺕` | U+02E95 | 康熙部首 | 11 |
| `⺩` | U+02EA9 | 康熙部首 | 9 |
| `⺄` | U+02E84 | 康熙部首 | 8 |
| `⺈` | U+02E88 | 康熙部首 | 2 |
| `⺼` | U+02EBC | 康熙部首 | 1 |
| `’` | U+02019 | 右单引号 | 1 |
| `⁉` | U+02049 | 叹问号 | 1 |
| `｢` | U+0FF62 | 半角片假名引号 | 1 |

**成因与处置**

| 类别 | 成因 | 建议 |
|---|---|---|
| 康熙部首 | 日本写本 OCR 噪声：CBETA 将「寶/宝」一类字映射到部首码位 U+2E80–2EFF | 按上下文订正为正字，如「比丘□⺩記」→「比丘□寶記」 |
| 半角片假名引号 | 全角「」与半角 ｢ 混用 | 改为全角「 |
| 右单引号 | 现代著作排版以 ’ 代顿号 | 改为「、 |
| 叹问号 | 现代著作作者自用字符，非转码错误 | 保留，或统一为「！？」 |

**经核查确认属正常者（非乱码）**：扩展区 A/B/C–F/G+ 汉字、兼容汉字 F900–FAFF、
缺字组合式方括号、几何符号 ○△□▲◇●■、IAST 拉丁转写、Latin-1 补充区、
西里尔／希腊字母（俄藏索书号）、日文假名、全角标点、组合附加符号／笔画。

> 编码层面完好：U+FFFD 替换字符、控制字符、代理项、非字符、PUA 私用区均为 **0**；
> UTF-8→Latin-1 误读痕迹（`Ã`/`Â`/`â€`/`锟斤拷`/`ï¿½`）命中 **0**。

## 九、图片与字体资源

- **图片**：CBETA 原文以专有标记书图（`【图：X60p0610_01.gif】`），非 Markdown 链接。
  本库一律改指为 `assets/` 之**相对路径**：

  ```
  【图：X60p0610_01.gif】
  →  `![X60p0610_01.gif](../../assets/figures/X/X60p0610_01.gif)`
  ```

  资源按 `assets/figures/<藏经代码>/<文件名>` 寻址（`assets/` 下共 35,743 个文件，
  `figures/` 20 藏、`gaiji-CB/` 28,384、`sd-gif/` 2,047、`rj-gif/` 167、`font/` 5）。
  **找不到资源文件者一律不做修正**，保留 CBETA 原标记，绝不臆造路径。
- **字体**：`assets/font/` 存 Ranjana／Siddam／SantipurOT 三种字形（.otf/.ttf），
  供悉曇、梵字渲染；**本库正文未引用任何字体文件**（无 `.otf`/`.ttf`/`@font-face`
  之引用），故字体链接无须改指。若日后正文引用，一并依上规则指向 `assets/font/`。
