## 2. 简体化规则

| 情形 | 处理 | 例 |
| --- | --- | --- |
| 繁体只有**一个**简体对应 | 转成该简体字 | `後` → `后`；`譯` → `译` |
| 繁体**没有**对应简体（异体／罕用字） | 保留繁体原字 | `㑮`、`𫝈` 之类扩展区字符 |
| 繁体对应多个简体，其中只有**一个常用简体**（其余为罕见异体字） | 转成该常用简体 | `開` → `开`；`願` → `愿`；`線` → `线`；`麵` → `面` |
| 繁体**语义真歧义** | **保留繁体原字** | `乾` → 干／乾；`於` → 于／於；`覆` → 覆／复 |

原则：**只保留真正需要依上下文判断的字，能确定的都转**。
逐字一对一替换不改变任何字词长度，故 `stats.text_length` 等统计数字
与繁体版完全一致。

「语义真歧义」的判准有二：

1. 繁体字本身也在 OpenCC 的多值列举之中，即该字在简体语境中**仍可保留**
   （`乾` 可作「乾坤」的乾、`於` 可作姓氏、`覆` 在「覆盖」中本就不改、
   `阪` 在「大阪」中不改、`彷` 可作「彷徨」、`徵` 可作「徵召」、
   `藉` 可作「狼藉」、`祇`（祇洹）／`薹`（薹臺）…）；
2. 列举中有**两个以上常用简体**，目标不同、语义有别
   （`畫` 画／划、`餘` 余／馀、`麼` 么／麽、`鍾` 钟／锺、`諮` 咨／谘…）。

「常用简体」的判准：**GB2312 汉字集 ∪ 单一对应表的目标字**
（罕见异体字如 `𫔭`、`𫖸`、`缐`、`麺` 因此不会被误判为歧义）。

## 3. 转换范围

JSON 内**所有字符串值**皆套用转换：书目（`work`）、标题、卷次索引、档头
（`header`）、注释索引（`notes`）、正文（`body`／`back` 节点树）、顶层 `text`
全文、统计文字等。

刻意**不转换**者：

- `source.xml_path`、`path` —— 指向**来源**语料（`xml-p5`）的路径，不随本目录改名；
- `lang`（`zh-Hant`）—— 语言标记维持原样。

**纯文本正文**：`txt/` 树与分类目录同构，每档一份纯文本，命名为
`<档号>.md`（例 `txt/1_阿含部/T01n0001.md`）。抬头与正文以空行分开：

```
集大乘相论                         ← 经名
                                    ← 空行
觉吉祥智菩萨造                      ← 作者译者题署，保留原分行
西天译经三藏朝奉大夫
试光禄卿传法大师赐紫
臣施护奉　诏译
                                    ← 空行
No. 1637                             ← 标号 NO.
                                    ← 空行
集大乘相论卷上                       ← 卷名
                                    ← 空行
归命妙吉祥菩萨摩诃萨。我今略释诸大乘相，……   ← 正文
```

抬头三类各自成段：**经名**（`work.title`）、**作者译者题署**（正文层 `<byline>`
元素，保留原分行）、**标号 NO.**（`docNumber`）；正文中的**品名**（`head`）与
**卷名**（`jhead`）亦各成独立段落，前留空行。

题署取自正文层的 `<byline>` 元素（作者、译者等署名块），保留其原有分行与
全形空格；正文中重复出现的题署不再重复。无题署元素者则退回 `work.byline`／
`work.authors`。不含任何标记或格式，
全部段落以 CRLF（`\r\n`）结尾，UTF-8 无 BOM。部别轴与撰述轴各建一条硬链接，
共 9980 条链接指向 4990 份唯一文件。

**通用字还原（sutra_txt）**：`w_normal.txt`「普及版通用字規範」左栏为组合表示式、
右栏为通用字（如 `[((企-止+ㄒ)/正)*(素-糸+ㄆ)]` → `鏺`）。`sutra_txt/` 的正文以方括号
原样写出该组合表示式（生僻字处），已依左栏为键替换为右栏通用字，计 2,048 处
（326 份档案）。该表只收 1,912 条组合式，故多数生僻字的方括号仍存，
如需扩充可补入 CBETA 档头的 `normalized form`。

**占位符替换**：CBETA 以私用区字符（PUA）标记生僻字与梵文悉昙字，本资料库已依
`w_normal.txt`「普及版通用字規範」（Big5 编码，含 1923 条组合表示式→通用字）将其还原；
组合表示式在通用字表中查不到者，取 CBETA 档头自带的 `normalized form`。全库正文占位符
由 222,095 处减至 135,948 处（替换 86,147 处）；余下 51,233 处有组合式而无对应汉字、
84,715 处为梵文悉昙字（`SD-xxxx`），无通用字可代，保持原样。通用字皆为单字，
故 `stats.text_length`、`char_count` 不变。对照表见 `gaiji_map.json`。

**消除重复**：同一文件内重复出现的相邻行予以合并——一连串相同的行只留一行，
两行一组的重复（A B A B）只留一组；卷首反复出现的题署（如「无著菩萨造／
大唐天竺三藏波罗颇蜜多罗译」）只留首次，抬头与正文共用同一份题署记录。
偈颂句不参与合并（其重复多出于文体本意）。合并反复执行至不再变化。

**语义分段**：CBETA 的一个 `<p>` 常是数百字的整段，故再依语义切分为可读段落——
依句读（`。！？`；拉丁文依句点加空白）切句，句首出现话语标记（復次、又、所以者何、
何者、佛告、爾時、問曰、善哉、當知…）即视为话题转换另起一段，段长超过 120 字亦于
句读处断开。音译对照表、校勘表等无句读之表另有退路切分（条目界、`，、；：`）。
全库共 589 万段，平均 43 字、中位 20 字、90 分位 112 字。切分只移动断点，不增删文字。

**硬换行已修复**：CBETA 原文按每行约 30 字排版折行。`text` 栏位中折行与段落
分隔同为 `\n`，平面文字无从分辨，故改由区块结构判定——块内（`p`／`head`／
`byline` 等内部）的 `lb` 视为排版折行予以合并，块间（`div` 等容器层）的 `lb`
视为段落分隔，偈颂 `lg` 内的 `l` 逐句成行。取字规则完全沿用 `sutra_lib_tool`
转换器（注文不收、校勘取 `lemma` 正读、`choice` 取 `corr`/`sic`、排版空白不计），
故正文文字与原 `text` 栏位逐字一致，仅换行位置不同。平均每档行数由 4132 降为 906。

由 `tools/reflow_txt.py` 生成；`tools/extract_txt.py` 为未折行的原始抽取。

**档案存放位置**：经文档案已全部迁出源藏经目录，各藏经索引统一收纳于 `sutra_cbeta/`
（如 `sutra_cbeta/T-大正新修大藏经/index.json`），仅存 `index.json`；正文存于分类
目录的 `files/` 下。`catalog.json`、各藏经 `index.json` 与各分类 `index.json` 的
`file` 栏位均已同步更新为新路径。

判定流程（工具：`tools/classify.py` + `tools/rules_block.py`）：

1. **标题规则表**，分层判定——特殊类目（目录／史传／事汇／外教／古逸／疑似）
   → 疏类（律疏／论疏／经疏）→ 主旨（经部、论部、密教、律藏）→ 诸宗部；
2. **同藏同卷多数类目推定**补足无规则命中者（置信度降为 `low`，依名登记）；
3. **撰述轴**依著者与题署判定，时代记号须为独立词方生效（「依民国十年…刻本印」
   之类附记不计），近现代人名名单只收不易与经文用语混淆者（「太虚」「星云」为
   常见佛学词，不采）；标「译」者归印度撰述，含藏·日·韩·越标记者归其他撰述，
   近现代人归现代撰述，其余汉地撰、著、编者归中国撰述；
4. **现代撰述不入二十六部**（该部只收历代经律论），仅列于「现代撰述」组。

全流程可由下列工具重建：

```bash
python3 tools/extract_meta.py     # 抽取全库题名/著者/卷次
python3 tools/classify.py         # 依规则表分类
python3 tools/build_index.py      # 产出各分类索引、总览与覆盖报告
python3 tools/migrate.py          # 把正文自源藏经目录迁入分类目录（硬链接）
python3 tools/restore_archives.py  # 档案受损时，自繁体底本重转并重新铺放
python3 tools/move_cbeta.py       # 将各藏经索引目录归并到 sutra_cbeta/
python3 tools/build_global_index.py # 生成全局索引与目录清单
python3 tools/extract_txt.py       # 抽取纯文本正文到 txt/（<档号>_txt.json）
```

分类为规则自动判定，`confidence` 标为 `low` 者为卷次推定或弱特征命中，建议抽样复核
（清单见《分类覆盖报告.md》第 3–4 节）。
